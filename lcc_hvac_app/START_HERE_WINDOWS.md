# Start Here On Windows

1. Unzip the package.
2. Open the folder.
3. Double-click:

```text
lcc_hvac_app/run_app.bat
```

4. If the browser does not open automatically, open:

```text
http://localhost:8501
```

The first run needs internet access. The launcher will install `uv`, create a local Python environment, install required packages, and start the app.

The app does not need VS Code.
